# מיגרציות DB

מקור האמת לשינויי סכימה. כל שינוי סכימה = קובץ SQL חדש כאן, בשם `YYYYMMDD_description.sql`, append-only (לא עורכים קובץ שכבר הורץ).

## איך מריצים

אין CLI מקושר כרגע - מריצים ידנית ב-Supabase Dashboard (SQL Editor), לפי סדר הקבצים, ומסמנים בטבלה למטה. בעתיד אפשר לעבור ל-`supabase db push`.

`supabase_schema.sql` בשורש הריפו הוא ה-baseline המלא (מצב הסכימה הנוכחי) - קבצי המיגרציה כאן הם דלתאות ממנו והלאה.
